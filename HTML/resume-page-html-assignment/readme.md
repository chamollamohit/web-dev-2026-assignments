# HTML Resume Page Assignment

A single-page, pure HTML resume website built as part of a Web Development assessment. This project focuses on using semantic HTML and traditional table attributes for layout without the use of external or internal CSS.

## 🚀 Live Demo
You can view the live project here:  
[**Live Resume Link**](https://scintillating-dango-cfa899.netlify.app/html/resume-page-html-assignment/)

## 📋 Features
- **Semantic Structure:** Uses `<h1>` through `<h3>` for clear information hierarchy.
- **Pure HTML Layout:** Employs traditional table attributes (`border`, `cellpadding`, `cellspacing`) to create structured data views for Experience and Education.
- **Clean Sections:** Includes dedicated areas for:
  - Header & Professional Title
  - About Me
  - Technical Skills List
  - Professional Experience Table
  - Project Showcases
  - Education Table
  - Contact Information

## 🛠️ Built With
- **HTML5:** Used for the structure and content.
- **Zero CSS:** Entirely styled using inline HTML attributes to demonstrate a fundamental understanding of HTML structure.
